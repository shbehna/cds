# JSON schemas

`odps-json-schema-v1.1.0.json` is the JSON schema of the
[Open Data Product Standard (ODPS)](https://bitol-io.github.io/open-data-product-standard/latest/)
v1.1.0, copied unmodified from
[bitol-io/open-data-product-standard](https://github.com/bitol-io/open-data-product-standard/tree/main/schema)
under the Apache License 2.0. ODPS publishes no Python package holding it, unlike ODCS
(`open-data-contract-standard`). The tests check the ODPS documents of the demo against it.
